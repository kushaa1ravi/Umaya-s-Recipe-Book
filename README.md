# Umaya's Heirloom Recipes 🍲

A lightweight, local-first Progressive Web App (PWA) designed to privately preserve, scale and cook cherished family recipes. Built specifically for mobile performance and completely offline use.

## Features
* **100% Local Storage:** No backend, no accounts, no cloud leaks. Your family secrets live entirely within your device's `localStorage`.
* **Installable PWA:** Add it to your iOS or Android home screen for a native app experience that opens instantly, even in airplane mode.
* **Distraction-Free Cook Mode:** A swipeable, full-screen step-by-step interface that keeps you focused while your hands are covered in flour.
* **Dynamic Servings Scaler:** Tap to instantly recalculate ingredient measurements for larger family gatherings.
* **Strict Taxonomy:** Recipes are rigorously organized by meal type, traditional Indian occasions and a 3-tier difficulty system (Easy, Medium, Umaya Mode).

## Tech Stack
* **Architecture:** Monolithic Vanilla JavaScript & HTML5
* **Styling:** Tailwind CSS (via CDN)
* **Icons:** Lucide Icons
* **Hosting:** GitHub Pages

## Installation & Deployment
This application requires zero build steps or package managers. 
1. Navigate to the live GitHub Pages URL on your mobile browser.
2. Tap **"Share"** (iOS) or the browser menu (Android) and select **"Add to Home Screen"**.
3. Open the app from your home screen and use it completely offline.
